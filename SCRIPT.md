# Tophexity — Project Explanation Script

---

**"Tophexity is an AI-powered career guidance platform I built using Next.js, TypeScript, and Tailwind CSS. It connects to a Python FastAPI backend hosted on Azure Functions."**

---

**"The platform serves two audiences — students from 8th grade through college, and working professionals looking to switch careers. The profile system uses a 5-step stepper covering personal info, education, work experience, skills with proficiency levels, and career goals."**

---

**"The careers page lets you explore available careers with advanced search and filters — by skill, education level, demand, and salary. Each career card expands to show details, and you can open a full modal with degrees, recommended colleges, entrance exams, scholarships, and resources."**

---

**"I added a favorites system using localStorage — you can heart any career to save it, and there's a Saved tab to quickly access them. There's also a multi-select mode where you can check two or more careers and compare them side-by-side through AI chat."**

---

**"The Ask AI button on career cards opens a new chat session with the career context pre-filled in the input. The user can then ask specific questions about that career path."**

---

**"The AI chat system has full session management — you can create, rename, pin, archive, and delete conversations. Messages are sent to the backend with a 120-second timeout for AI responses, and there's a thinking indicator with an elapsed timer while you wait."**

---

**"When a profile is complete — meaning it has a name and at least skills, target fields, or interests — the system automatically redirects to the chat to generate personalized career recommendations. There's also a manual Generate button on the recommendations page."**

---

**"The roadmaps section shows learning paths tied to specific careers, with pause, resume, and cancel controls. Backup plans let you track alternative career paths. The portfolio section supports 17 different item types — from internships and projects to publications and awards."**

---

**"The admin panel is protected by a secret code. Once inside, you can import careers via JSON, edit career details, or delete entries."**

---

**"The entire UI supports light, dark, and system themes with a visual theme picker in settings. There's also a customizable sidebar where users can show, hide, and reorder navigation items."**

---

**"Everything is connected to the live backend API with automatic JWT token refresh on expiration, so the session stays active without the user having to log in again."**

---

**"Tophexity makes career guidance accessible and personalized through AI — something that's usually limited to expensive counselors or generic job boards."**
